# Boba Shop 🧋

**Boba Shop ** was created for **Boba Bash**, held in Indiranagar, Bengaluru, Karnataka, India.

## About the Project
The game was conceptualised and designed by **Hrishith Ranjan**. The artwork and core creative ideas are entirely human-made, while AI assistance through [Bolt.new](https://bolt.new) was used to help with development and implementation.
